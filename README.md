# TicketFlow - Ticket Management System

TicketFlow is a full-stack complaint and ticket management system developed with ASP.NET Core Web API, React, and MSSQL.

## Technologies

- ASP.NET Core Web API
- React.js
- MSSQL
- Entity Framework Core
- JWT Authentication
- Axios
- React Router
- React Toastify

## Features

- User registration and login
- JWT based authentication
- Role based authorization
- Admin, Moderator and User panels
- Ticket creation and tracking
- Ticket status management
- User feedback and rating system
- Moderator performance reports
- Date based report filtering
- PDF and Excel report export
- Responsive modern UI

## User Roles

### Admin
- Creates moderators
- Views system reports
- Tracks moderator performance
- Exports reports as PDF and Excel

### Moderator
- Views assigned tickets
- Updates ticket status
- Tracks user feedback

### User
- Creates tickets
- Tracks ticket progress
- Gives feedback after resolution
